1. 엔센 12개 보장 (4레벨 포함)
· 4레벨 엔센 포함 총 12개 보장
· 단체 이민 시 최소 기반 없이 시작하지 않도록 안정적인 출발 지원

2. 요새 / 성채 분배
· 요새 4개 / 성채 1개 제공
· 초기 정착 이후 서버 안정화 시
기여도, 점수, 랭킹 기준으로 합리적 재분배 진행

3. 서버전 메인 참여 / 카랠 협력 운영
· 서버전에 진심으로 참여하는 구조
· 강성 서버와의 전투에서도 승리 경험 보유
· 전적 : 15전 12승 달 2개 별1개 (※별 1개는 타 연맹 보유)

4. 서리 / 드엠 협력 가능
· 연맹 간 협의를 통한 유동적 협력 운영
· 첫 서리 이벤트에서도 연합 운영 경험 보유
· 서리 서버 연합 단합으로 4강 진출 달성
· 드엠 서버 연합 체제로 출전해 연맹 4위 / 개인(7위) 기록

5. 연구 만렙 연맹 제공 가능
· 연구 만렙 빈 연맹 2개 보유
· WON 연맹(행성 1 / 유성 7)
→ 합병 형태 참여 가능
→ 단체 이민 시 매우 유리한 선택지

6. 초기 정착 전폭 지원
· 깃발 / 센터 / 인원 부족 등 초기 문제 적극 지원
· 단체 이민 시 발생하는 정착 스트레스 최소화
· 안정적으로 자리 잡을 수 있도록 지속 지원
